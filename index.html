featured.project · personal project TypeScript · Playwright MCP · Claude Code

AI-Augmented Playwright Framework

A Playwright framework where Claude Code agents turn acceptance criteria into tests, and repair broken tests without hiding real bugs.

View on GitHub →
  • A Claude Code command turns acceptance criteria into Playwright tests, with an approval gate.
  • Writer and healer agents use Playwright MCP to check live locators and fix test defects, not app defects.
  • Guardrails stop the healer weakening assertions or adding waits. Passing specs rerun 3 times to catch flakiness.
  • A custom reporter tracks per-test pass rates, flaky runs and trends, persisted by GitHub Actions CI.
